# Example Prompt — To-Do App

**Intent:** generate

**Prompt:**

```
Build a modern to-do app in React + TypeScript with:
- Add, edit, and delete tasks
- Mark tasks as complete (checkbox)
- Filter by All / Active / Completed
- Drag-and-drop reordering (HTML5 drag API, no extra library)
- Local storage persistence
- Dark mode (Tailwind, system preference)
- A clean, minimal design with smooth transitions

Use a single App.tsx file with inline Tailwind classes.
No external state management library — just useState and useReducer.
```

**Expected output:**
A single-file React app (`src/App.tsx`) with full to-do functionality,
no backend, no additional dependencies beyond React and Tailwind.
