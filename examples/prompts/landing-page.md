# Example Prompt — SaaS Landing Page

**Intent:** generate

**Prompt:**

```
Create a SaaS landing page for a fictional project management tool called "TaskFlow".
The page should have:
- Navigation bar with logo, links (Features, Pricing, About), and "Get Started" CTA
- Hero section: large headline, sub-headline, two CTA buttons, and a product screenshot placeholder
- Features section: 3 cards with icon, title, and description
- Pricing section: 3 tiers (Free, Pro $12/mo, Team $29/mo) with feature lists and CTAs
- Testimonials: 3 quotes with avatar placeholder, name, and role
- FAQ: 5 collapsible questions
- Footer with links and copyright

Use React + TypeScript + Tailwind CSS.
Everything in one App.tsx file.
Use a blue/indigo color scheme.
```

**Expected output:**
`src/App.tsx` — a complete static landing page with all sections.
No routing, no backend.
